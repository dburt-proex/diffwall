# DiffWall v0.2.0

DiffWall v0.2.0 is the first pinned, independently deployable release of the deterministic PR and structured-action firewall.

## What ships

- deterministic `ALLOW`, `REVIEW`, and `HALT` routing;
- composite GitHub Action with a committed JavaScript runtime;
- Markdown, JSON, and SARIF reports;
- PR comment create/update behavior with evidence fallbacks;
- CODEOWNERS-aware reviewer suggestions;
- Node/Express, Python/Django, and Terraform policy packs;
- unsafe GitHub Actions workflow detection;
- Python structured-action firewall;
- Node 20/22 and Python 3.11/3.12 release evidence;
- synthetic large-diff benchmark, package inventory, audit evidence, archive, and checksum;
- buyer-facing pilot runbook and controlled demo media.

## Pinned installation

```yaml
- uses: dburt-proex/diffwall/action@v0.2.0
  with:
    base: ${{ github.event.pull_request.base.sha }}
    head: HEAD
    config: rules/default.yml
    format: markdown
    fail_on_halt: true
    github_token: ${{ github.token }}
```

## Verification boundary

The released commit is rebuilt and retested immediately before publication. The release includes an action archive and matching SHA-256 checksum.

This release is suitable for controlled evaluation and pilot use. It is not a certification, a guarantee of complete risk prevention, or evidence of universal repository compatibility, customer adoption, or unattended production safety.

## Known residual risks

- external buyer validation is incomplete;
- long-lived audit storage remains caller-owned;
- performance evidence is synthetic;
- independent penetration testing and long-duration production validation remain future assurance work.

See `docs/releases/v0.2.0-decision.md` for the evidence, owner authorization, governed exception, and reversal condition.
